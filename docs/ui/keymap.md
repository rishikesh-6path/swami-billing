# Keymap

Source of truth is KICKOFF section 7. The shortcut set was kept even though ShopLedger is now standalone, so staff learn one set of keys. Every new screen appends its keys here in the session that builds it.

Letter keys on the home screen only work when the cursor is not inside a box. Function keys and Ctrl/Alt combinations work everywhere on their screen.

screen | key | action
--- | --- | ---
Every screen | Esc | Go back one screen (asks first if a bill has unsaved work)
Every screen | F10 | Calculator (Enter works out the sum, Esc closes)
Home | F1 | Help with the list of keys and the "About this computer" panel
Home | F8 | New sale
Home | F9 | New purchase
Home | F6 | New receipt (money in)
Home | F5 | New payment (money out)
Home | F7 | New journal entry
Home | F2 | Add an item
Home | F3 | Add a customer
Home | R | Reports list
Home | L | Account ledger
Home | S | Stock report
Home | G | Item history
Home | T | Trial balance (owner)
Home | B | Balance sheet (owner)
Home | V | GST summary (owner)
Home | D | Find a bill
Home | Alt+B | Find a sale to change
Home | U | Switch user
Bill, receipt, payment, journal, contra, stock screens | F2 | Save
Bill, receipt, payment, journal, contra, stock screens | Enter | Next box
Bill, receipt, payment, journal, contra, stock screens | Shift+Enter | Previous box (item grid)
Bill, receipt, payment, journal, contra, stock screens | F5 | Show the list for the current box
Item grid | F7 | Repeat the line above
Item grid | F9 | Delete the current line
Item grid | F4 | Standard note
Sale, purchase, returns | F12 | Copy the last bill of the same kind
Item grid | Esc | Close the open list first, then leave the bill
Find a bill | Type | Search by customer name, bill number or note
Find a bill | Up/Down, Enter | Choose and open a bill
Bill view | Alt+B | Change this bill (replaces it with a corrected one)
Bill view | Alt+C | Cancel this bill (reason required)
Bill view | Ctrl+P | Print preview (A4 or 80 mm roll)
Print preview | Enter | Print
Print preview | Esc | Close
Report | Ctrl+E | Save as spreadsheet (CSV)
Report | Ctrl+P | Print the report
Items and customer lists | Type, Up/Down, Enter | Search, choose, open
Items list | F2 | Add an item
Customer and supplier lists | F3 | Add one
Item and party forms | F2 | Save
Item and party forms | Enter | Next box
Settings | Alt+1 to Alt+6 | Shop details, Printing, People, Standard notes, Closing, Backup
Settings | F2 | Save the current section
Add from a Spreadsheet | I, C, S | Choose a file for items, customers, suppliers
Confirm questions | Y / N, Enter, Esc | Yes, no, confirm the highlighted button, cancel
